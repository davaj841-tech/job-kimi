# ورود گروهی سوالات استخدامی

> محتوای سوالات باید **قانونی** باشد: تألیف خودتان، منابع رسمی عمومی، یا مجوز کتبی ناشر. کپی از سایت‌های تجاری بدون مجوز یا هرگونه دسترسی غیرمجاز ممنوع است.

## دو مسیر جدا در پنل

### الف) ورود سوالات به آزمون موجود

`/admin` → سوالات → **ورود Excel**

1. یک **آزمون** بسازید/انتخاب کنید  
2. **دانلود نمونه XLSX یا CSV**  
3. ردیف‌ها را پر کنید و آپلود کنید  

API: `POST /api/v1/admin/questions/import` (`file` + `exam_id`)

### ب) ورود آزمون کامل (نام آزمون + سوالات)

`/admin` → سوالات → **ورود آزمون کامل**

1. **دانلود فایل نمونه XLSX** (دو شیت: `آزمون` و `سوالات`)  
2. شیت آزمون را با نام و تنظیمات پر کنید  
3. شیت سوالات را پر کنید و آپلود کنید  

آزمون **جدید** ساخته می‌شود؛ نیازی به انتخاب آزمون قبلی نیست.

API:

- `GET /api/v1/admin/questions/import-exam-sample`
- `POST /api/v1/admin/questions/import-exam` (فقط `file`)

## ستون‌های سوالات

| ستون فارسی | معادل انگلیسی | الزامی | توضیح |
|------------|---------------|--------|--------|
| متن_سوال | question_text | بله | صورت سوال |
| گزینه_الف … گزینه_د | option_a … option_d | بله | چهار گزینه |
| پاسخ_صحیح | correct_answer | بله | الف/ب/ج/د یا a/b/c/d |
| درس | subject | خیر | ریاضی، ادبیات، معارف، انگلیسی، شیمی، فیزیک، هوش، عمومی، … |
| توضیحات | explanation | خیر | تحلیل پاسخ درست |
| سطح | difficulty | خیر | آسان / متوسط / سخت (خالی = متوسط) |
| نام_آزمون | exam_title | اگر آزمون از لیست انتخاب نشده | تطبیق با عنوان آزمون |
| شناسه_آزمون | exam_slug | اختیاری | slug آزمون |
| سال | exam_year | خیر | مثلاً 1402 |
| منبع | source | خیر | مثلاً «دفترچه عمومی — نمونه تألیفی» |

اگر در مودال «ورود Excel» آزمون را انتخاب کنید، ستون نام‌آزمون لازم نیست.

## مثال CSV (فقط سوالات روی آزمون موجود)

```csv
درس,متن_سوال,گزینه_الف,گزینه_ب,گزینه_ج,گزینه_د,پاسخ_صحیح,توضیحات,سطح,سال,منبع
ریاضی,حاصل ۲×۳ کدام است؟,۵,۶,۷,۸,ب,۲×۳=۶,آسان,1402,نمونه تألیفی
```
